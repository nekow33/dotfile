# Emacs 使用手册（基于当前配置）

> 配套 `config/init.el`，覆盖本套配置的全部快捷键与功能用法。
> 排版约定：`SPC` = 空格键（leader 键），`C-x` = Ctrl+x，`M-x` = Alt+x，`g`/`d`/`c` 等为普通按键。

---

## 1. 基本概念

- **leader 键**：`SPC`（空格），在 evil normal/visual 态下按 `SPC` 后跟按键序列触发常用操作
- **模式**：normal（普通，按 `Esc` 进入）、insert（插入，按 `i`）、visual（可视，按 `v`）
- **状态栏**：右侧显示当前模式；有 rime 时显示 `中`/`英` 输入法状态
- **启动**：Windows 直接双击/运行 emacs；WSL 用 `emacs`（Wayland 渲染）

## 2. SPC leader 键位总表

### 文件 `SPC f`
| 按键 | 功能 |
|------|------|
| `SPC f f` | 打开文件（find-file） |
| `SPC f r` | 最近打开的文件 |
| `SPC f s` | 保存当前文件 |

### Buffer `SPC b`
| 按键 | 功能 |
|------|------|
| `SPC b b` | 切换 buffer（模糊搜索） |
| `SPC b d` | 关闭当前 buffer |
| `SPC b n` / `SPC b p` | 下一个 / 上一个 buffer |

### 窗口 `SPC w`
| 按键 | 功能 |
|------|------|
| `SPC w h/j/k/l` | 焦点移到左/下/上/右窗口 |
| `SPC w d` | 关闭当前窗口 |
| `SPC w /` | 垂直分屏 |
| `SPC w -` | 水平分屏 |

### 搜索 `SPC s`
| 按键 | 功能 |
|------|------|
| `SPC s s` | 当前 buffer 内搜索行 |
| `SPC s f` | 过滤显示匹配的行（聚焦） |
| `SPC s r` | **项目内 ripgrep 搜索**（不载入文件，大项目不卡） |

### 复制粘贴 `SPC y`
| 按键 | 功能 |
|------|------|
| `SPC y p` | 剪贴板历史（yank-pop） |
| `SPC y r` | 替换为剪贴板历史 |

### 帮助 `SPC h`
| 按键 | 功能 |
|------|------|
| `SPC h f` | 查函数文档 |
| `SPC h v` | 查变量文档 |
| `SPC h k` | 查按键绑定 |
| `SPC h m` | 当前模式文档 |
| `SPC h b` | 当前 buffer 所有绑定 |

### 其它
| 按键 | 功能 |
|------|------|
| `SPC SPC` | M-x（执行任意命令） |
| `SPC q q` | 退出 Emacs（y/n 确认） |
| `SPC r e` | 重新加载当前 elisp buffer |
| `SPC d d` | 打开 dirvish 文件管理器 |
| `SPC d o` | dirvish 快速访问菜单 |
| `SPC e e` | 打开 eshell |
| `SPC e c` | 运行单条 shell 命令 |
| `SPC l ...` | LSP 操作（见第 6 节） |

## 3. Evil 基础操作（vim 习惯）

### 移动
`h j k l` 左/下/上/右；`w e b` 词移动；`0 ^ $` 行首/行首非空/行尾；`f t F T` 字符搜索；`gg` 文件头、`G` 文件尾、`%` 匹配括号

### 编辑
| 按键 | 功能 |
|------|------|
| `i a I A o O` | 插入/追加/行首插/行尾插/下方开行/上方开行 |
| `x` / `X` | 删字符 / 删前字符 |
| `d` + 移动 | 删除（如 `dw` 删词、`dd` 删行） |
| `c` + 移动 | 修改（删后进插入态） |
| `y` + 移动 | 复制（`yy` 复制行） |
| `p` / `P` | 粘贴到后 / 粘贴到前 |
| `r` | 替换单个字符 |
| `u` / `C-r` | 撤销 / 重做 |
| `>>` / `<<` | 缩进 / 反缩进 |
| `gU` / `gu` / `g~` | 大写 / 小写 / 切换大小写 |
| `J` | 合并下一行 |

### 选择与搜索
| 按键 | 功能 |
|------|------|
| `v` / `V` / `C-v` | 字符 / 行 / 块选择 |
| `/` 搜索词 + 回车 | 搜索并高亮 |
| `n` / `N` | 下一个 / 上一个匹配 |
| **`g c`** | **取消搜索高亮**（任意 buffer） |
| `*` / `#` | 搜索光标下单词（前向/后向） |

## 4. 补全与搜索（vertico + orderless + corfu）

- **`M-x` / `SPC SPC`**：命令补全，空格分词模糊匹配（orderless）
- **`SPC b b` / `SPC f f`**：buffer / 文件补全，同样支持模糊
- **corfu 弹窗补全**（代码输入时自动弹出）：
  - 输入 2 个字符后自动弹出候选
  - `C-n` / `C-p` 上下选择；`TAB` 确认；`RET` 选中
- **`M-p`**：剪贴板历史选择（consult-yank-pop）

## 5. 文件管理 dirvish

### 打开
`SPC d d`（或 `SPC f f` 输入目录路径、`C-x d`）

### 导航
| 按键 | 功能 |
|------|------|
| `j` / `k` | 下 / 上移动 |
| `h` | 返回上级目录 |
| `l` / `RET` | 进入目录 / 打开文件 |
| `g d` | **快速跳到任意路径**（输入路径，支持 Tab 补全） |
| `O` | 快速访问菜单（h=Home d=Downloads c=Code e=.emacs.d t=TrashCan） |
| `R` | 刷新 |
| `q` | 退出 dirvish |
| `g c` | 取消搜索高亮 |

### 文件操作
| 按键 | 功能 |
|------|------|
| `c` | 复制（到另一个 dirvish 窗口 = 智能目标） |
| `r` | 重命名 |
| `+ d` / `+ f` | 新建目录 / 新建文件 |
| `m` / `u` / `U` / `t` | 标记 / 取消标记 / 全部取消 / 反选 |
| `x` / `D` | 删除（标记的） / 直接删除 |
| `%` | 批量正则重命名 |
| `M-l` / `M-s` | 切换布局 / 设置菜单 |
| `TAB` | 子树展开/折叠 |

### 鼠标
左键单击打开/折叠，右键打开文件，中键在新窗口打开；删除进回收站。

## 6. 代码编辑（eglot + corfu）

打开 `rust`/`c`/`c++` 文件自动启动 LSP。**`SPC l`** 前缀：

| 按键 | 功能 |
|------|------|
| `SPC l a` | 代码操作（重构建议） |
| `SPC l r` | 重命名符号 |
| `SPC l f` | 格式化整个 buffer |
| `SPC l d` / `SPC l D` | 跳转到定义 / 声明 |
| `SPC l i` | 查找实现 |
| `SPC l R` | 查找所有引用 |
| `SPC l h` | 悬停文档（hover） |
| `SPC l o` | 整理 import |
| `SPC l s` | 工作区符号搜索 |
| `SPC l e` | 诊断列表（flymake 错误） |

错误/警告实时显示在行尾（flymake），保存时自动检查。

## 7. 中文输入法 rime

| 按键 | 功能 |
|------|------|
| `C-\` | 开关 rime 输入法 |
| `M-j` | **中/英切换**（输入时也生效） |
| `C-M-j` | 强制中文（无视规则，单次输入） |
| `C-;` | 当前拼音首项上屏并切换输入法 |
| `ESC` | 首项上屏并回到 normal 态（evil 友好） |
| `C-\`` | 打开 RIME 方案菜单 |

- 状态栏实时显示 `中`（紫色）或 `英`（灰色）
- evil normal/visual 态自动用英文（不误输中文）
- 候选显示在 minibuffer（不遮挡代码）

## 8. Eshell 与终端（Eat）

### Eshell
| 按键 | 功能 |
|------|------|
| `SPC e e` | 打开 eshell |
| `SPC e c` | 运行单条命令 |
| `C-l` / `C-c C-l` | 清屏 |
| `M-p` / `M-n` | 上一条 / 下一条历史 |

- 彩色提示符：`用户@主机 目录 λ`
- `htop`/`vim`/`ssh` 等 TUI 程序自动在 **Eat** 中运行（不再用内置 term）

### Eat（真终端）
| 按键 | 功能 |
|------|------|
| **`SPC e t`** | 打开 Eat 终端 |
| `C-c C-e` | 切到 emacs 输入模式（Emacs 键位） |
| `C-c M-d` | 切到 char 模式（所有键直达终端） |
| `C-c C-l` | 切到 line 模式（整行编辑，像 shell-mode） |
| `C-c C-j` | 切回 semi-char 模式（默认） |
| `C-c C-k` | 杀掉终端进程 |
| `C-q` | 把下一个按键发送给终端（如 C-g） |
| `C-y` / `M-y` | 粘贴 / 剪贴板历史到终端 |

- 默认 **semi-char 模式**：大多数按键直达终端，C-c/C-x/C-g 等保留给 Emacs
- 能跑 htop / vim / ssh / tmux / fzf 等一切交互程序
- evil 键位由 evil-collection 自动接管
- 适合：ssh 远程、git 交互、REPL、任何 eshell 跑不了的程序

## 9. 多光标编辑（evim）

| 按键 | 功能 |
|------|------|
| `C-n`（normal 态，光标在单词上） | 选中该单词全部出现 |
| `n` / `N` | 添加下 / 上一个匹配 |
| `q` / `Q` | 跳过当前 / 移除当前光标 |
| `Tab` | 切换 光标模式 ↔ 扩展模式 |
| `i a I A o O` | 在所有光标处同步输入（Esc 结束） |
| `d/c/y` + 移动 | 删除/修改/复制（所有光标） |
| `p` / `P` | 粘贴（与光标一一对应） |
| `u` / `C-r` | 撤销 / 重做 |
| `\ z` / `\ @` / `\ :` | 运行命令 / 宏 / ex 命令（leader 前缀 `\`） |
| `Esc` | 退出 |

详细教程见同目录 `evim-guide.md`。

## 10. 剪贴板与鼠标

- **鼠标拖动选中 → 自动复制**（0.5s 后同步到系统剪贴板，Windows/WSL 通用）
- **中键**：粘贴到光标处
- **Emacs 内粘贴**：`C-y`（insert 态）或 normal 态 `p`
- 剪贴板历史：`SPC y p`；`M-p` 快速选择
- `kill-ring` 和输入历史重启后保留（savehist）

## 11. 大文件处理

| 文件大小 | 行为 |
|---------|------|
| 行长 >500 字符 | so-long 自动降级（去高亮，显示正常） |
| >8 MB | 自动关闭高亮/行号/版本控制，状态栏显示 `[big]` |
| >64 MB | 再关闭撤销（省内存） |
| >100 MB | 打开时询问：`o` 正常打开 / `v` vlf 分块 / `a` 中止 |

- 项目搜索用 `SPC s r`（ripgrep，不载入大文件）
- 双向文本重排已全局关闭（超长行不卡）

## 13. 常见问题速查

| 问题 | 解决 |
|------|------|
| 搜索后高亮去不掉 | `g c` |
| 输入法开了但输出英文 | `M-j` 切回中文 |
| 想用系统剪贴板 | 鼠标选中即可；或 evil 里 `"+y` / `"+p` |
| 大文件打开卡 | 自动优化已生效，状态栏见 `[big]` |
| 找不到命令 | `SPC SPC` 输入命令名模糊搜索 |
| 某个键位是什么 | `SPC h k` 然后按那个键 |
| WSL 字体糊 | 确认用 pgtk 版 emacs + `GDK_BACKEND=wayland`（见 README） |
