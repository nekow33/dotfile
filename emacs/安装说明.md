# Emacs 配置安装说明（WSL / Arch Linux）

本配置为基于 **straight.el** 的单文件 `init.el`。Emacs 包由 straight.el 在首次启动时
自动从 GitHub 拉取、编译，无需手动安装；但**部分功能依赖系统级软件**（编译模块、
外部程序、字体等），需先装好。

本文档以本机实测环境为基准：**WSL2 + Arch Linux + Emacs 31.1**。

---

## 1. 运行环境要求

| 项目 | 要求 |
|---|---|
| Emacs | ≥ 29，推荐 30/31 |
| 特性 | 需启用三种能力（见下方自检）：native-comp、动态模块、tree-sitter |
| 包管理 | straight.el（首次启动自动引导，无需预装） |

Emacs 能力自检（应输出 `native-comp=t module=.so treesit=t`）：

```sh
emacs -Q --batch --eval '(princ (format "native-comp=%s module=%s treesit=%s\n" \
  (and (fboundp (quote native-comp-available-p)) (native-comp-available-p)) \
  module-file-suffix (and (fboundp (quote treesit-available-p)) (treesit-available-p))))'
```

> `module-file-suffix` 为 `.so` 才能用 vterm / rime 等动态模块。

## 2. 系统级依赖

### 2.1 必需（否则配置无法完整工作）

| 软件包 | 用途 | 对应功能 |
|---|---|---|
| `emacs` | 本体（带 native-comp/模块/treesit） | 全部 |
| `git` | straight.el 拉取包 | 包管理 / magit / diff-hl |
| `gcc`、`make` | 编译动态模块 | emacs-rime |
| `cmake`、`libvterm` | 编译 vterm 模块 | vterm 终端 |
| `librime` | RIME 中文输入法引擎 | emacs-rime |
| `libgccjit` | native-comp 编译包 | 启动/运行性能 |

一键安装（Arch）：

```sh
sudo pacman -S --needed git gcc make cmake pkg-config libvterm librime libgccjit
```

> - Emacs 若无包管理器版本，可自行编译或使用 AUR。
> - `libgccjit` 需与 Emacs 的 native-comp 匹配；若 Emacs 是自编译的，构建时已需要它。
> - `pkg-config` 便于 emacs-libvterm 探测系统 libvterm（否则会联网下载内置版）。

### 2.2 推荐 / 可选（按需，缺失只影响对应功能）

| 软件包 | 用途 | 对应功能 | 本机状态 |
|---|---|---|---|
| `ripgrep` | 全文检索 | `SPC sr` / `consult-ripgrep` | 已装 |
| `fd` | 更快文件查找 | dirvish 的 fd 集成 | **未装** |
| `clang`（含 clangd） | C/C++ LSP + clang-format | eglot / apheleia | 已装 |
| `rustup`（rust-analyzer、rustfmt 组件） | Rust LSP / 格式化 | eglot / apheleia | rustc 有，**rust-analyzer 未装** |
| `nodejs` + `prettier` | 前端格式化 | apheleia | node 已装 |
| `python` + `black`/`isort` | Python 格式化 | apheleia | python 已装 |
| 语言服务器 | 各类 LSP | eglot | 按语言自选 |
| tree-sitter 语法库 | C/C++ 等的 ts 模式 | `c-ts-mode` 等 | 需 Emacs 内安装 |

补充命令示例：

```sh
# 检索与查找
sudo pacman -S --needed ripgrep fd

# C/C++
sudo pacman -S --needed clang

# Rust（rustup 管理）
rustup component add rust-analyzer rustfmt

# 前端 / Python 格式化
sudo pacman -S --needed nodejs
npm install -g prettier
pip install black isort
```

tree-sitter 语法库（Emacs 用 `.so`，与系统 `tree-sitter` 二进制不同）：

```
M-x treesit-install-language-grammar RET c RET
M-x treesit-install-language-grammar RET cpp RET
```

配置对缺失语法库做了保护：没有时自动沿用 `cc-mode`，不会报错。

### 2.3 字体（GUI 图标所必需）

GUI 下 nerd-icons / doom-modeline / dirvish 的图标依赖 **Nerd Font**。本机使用
`Maple Mono NF CN`（需带 `NF` 的版本），并配有 `Symbols Nerd Font` 作为兜底。

- 安装：把字体文件放到 `/usr/local/share/fonts/` 或 `~/.local/share/fonts/`，然后执行
  `fc-cache -f`；
- 配置中已设定字体族名，字体缺失时图标会显示为方块；
- **终端（tty）下无法使用 face 字体**，配置已自动降级：tty 时关闭 modeline 图标、
  去掉 dirvish 文件图标、subtree 指示器改用 `+/-` ASCII。若想在终端也看到图标，
  需把**终端模拟器**（Windows Terminal / WezTerm 等）的字体设为 Nerd Font。

## 3. 安装步骤

1. **放置配置**

   ```sh
   mkdir -p ~/.emacs.d
   cp init.el ~/.emacs.d/init.el
   ```

2. **首次启动 Emacs**

   ```sh
   emacs        # GUI（WSLg）
   # 或
   emacs -nw    # 终端
   ```

   首次启动会由 straight.el 自动下载并编译所有包（需要联网，较慢），
   并生成 `~/.emacs.d/straight/`、`eln-cache/` 等目录。

3. **编译动态模块**（首次各触发一次）

   - **vterm**：`M-x vterm`（或 `SPC et`）时若提示编译模块，选 `y`；配置中已预编译过，
     换机器后需重新生成 `straight/build/vterm/vterm-module.so`。
   - **emacs-rime**：首次按 `C-\` 会自动编译 `librime-emacs.so`（需 `gcc` + `librime`）。

   手动重编：`M-x vterm-module-compile`（vterm）；rime 重新加载即可。

4. **（可选）vterm shell 集成**（目录/prompt 跟踪、buffer 标题）

   在 `~/.bashrc` 末尾加入：

   ```sh
   [ -n "$EMACS_VTERM_PATH" ] && source "$EMACS_VTERM_PATH/etc/emacs-vterm-bash.sh"
   ```

5. **（可选）让 git 用 Emacs 编辑提交信息**

   ```sh
   git config --global core.editor "emacsclient -nw"
   ```

## 4. 目录结构

```
~/.emacs.d/
├── init.el          # 主配置（本仓库）
├── custom.el        # 可选：customize 保存的变量（存在时自动加载）
├── recentf          # 最近文件（自动生成）
├── history          # savehist 历史（自动生成）
├── straight/        # straight.el：repos（源码）、build（编译产物）
├── eln-cache/       # native-comp 缓存
└── rime/            # emacs-rime 数据
```

## 5. 功能与外部依赖对照表

| 功能 | 入口 | 依赖 |
|---|---|---|
| 终端 vterm | `SPC et` | `libvterm` + `cmake` + `gcc` |
| 终端 eshell | `SPC ee` | 无（内置） |
| 中文输入法 rime | `C-\` | `librime` + `gcc` |
| 补全/搜索 | `SPC bl` / `SPC sr` | `ripgrep`（rg 搜索） |
| LSP | `SPC l…` | eglot（内置）+ 各语言 LSP server |
| 保存格式化 | 自动 | apheleia + 对应 formatter |
| Git | `SPC g…` | `git` |
| 图标 | 自动 | Nerd Font（仅 GUI） |
| tree-sitter 模式 | 自动 | Emacs 语法库 `.so` |

## 6. 常见问题

- **首次启动很慢 / 卡住**：straight.el 正在拉包 + native-comp 编译，属正常；耐心等待或
  查看 `*straight-process*` 缓冲区。
- **图标显示成方块**：系统缺 Nerd Font（GUI）；或终端未设 Nerd Font（tty，见 2.3）。
- **终端里 markdown/org 标题不放大**：终端字号固定，Emacs 在 tty 下忽略 face `:height`，
  属正常限制，非配置问题。
- **vterm 报缺模块**：未安装 `cmake`/`gcc`/`libvterm`，或模块未编译，执行
  `M-x vterm-module-compile`。
- **rime 不可用**：缺 `librime` 或未编译模块；先装 `librime` 再按 `C-\`。
- **换机器/重装**：直接复制 `init.el` 即可，包与模块会在首次启动自动重建
  （建议不要拷贝 `straight/`、`eln-cache/`，避免路径/架构不一致）。

## 7. 快速自检清单

```sh
# 核心工具
for c in emacs git gcc make cmake pkg-config rg; do printf '%-12s %s\n' "$c" "$(command -v $c || echo MISSING)"; done
# 模块相关库
pacman -Q libvterm librime libgccjit 2>/dev/null
# 字体
fc-list | grep -i 'nerd'
# Emacs 能力
emacs --version | head -1
```

全部具备即可获得与开发机一致的体验。
